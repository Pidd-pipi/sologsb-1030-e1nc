# 飞行检查单编写与校验工具（sologsb-1030）

用于按飞行阶段编写、校验、复核和冻结操作检查单。项目实现完整的数据模型、本地持久化、版本控制、快捷键、拖拽排序、校验、修订差异与打印导出。

## 功能

- 阶段与检查项：维护飞行阶段、挑战语、预期回应、关键标记、前置条件和异常处置。
- 运行条件配置：每项可标注必须满足夜航、结冰条件或仪表飞行（IFR）中的哪些要求；多选表示必须同时满足，全部不选则任意航班都执行。
- 执行视图：按本次航班选择的运行条件实时计算各阶段可用项；条件不足的检查项进入排除区，并逐项说明缺少哪些条件，可在排除区直接补齐。关键项被排除时产生阻断错误，不能提交复核或冻结（提供“一键补齐所需条件”）。
- 快速录入：可使用 `/` 聚焦挑战语，`Cmd/Ctrl+Enter` 新增检查项，`Alt+↑/↓` 调整当前项位置。
- 拖拽排序：检查项可拖动并跨阶段移动，阶段也可调整先后顺序。
- 发布校验：
  - 重复挑战语与高频回应；
  - 缺少挑战语或预期回应；
  - 自引用、已删除或顺序不可达的前置条件；
  - 飞行阶段顺序异常；
  - 空阶段提示；
  - 关键项被当前航班运行条件排除（阻断）。
- 发布流程：编辑中 → 复核中 → 冻结；存在阻断错误时不能提交复核或冻结。
- 修订控制：冻结后可创建新修订；冻结快照保留阶段、检查项（含每项运行条件要求）、时间、复核说明和冻结时的航班条件选择。创建修订不重置任何设置，原条件继续有效。
- 版本差异：可选择当前版本或任意冻结版本作为基准与比较版本，逐项保留每项配置的前后值（挑战语、回应、关键、阶段/序号、前置条件、异常处置、运行条件要求），显示新增、删除、修改和阶段调整。
- 键盘与历史：支持撤销、重做、手动保存，最近 40 次编辑可回退。
- 离线保存：所有数据（含本次航班条件选择）写入浏览器 `localStorage`，刷新后读回；旧存档首次加载自动补齐运行条件字段。
- 只读预览与打印：提供对话框预览、浏览器打印/PDF，以及独立打印版 HTML 导出。

## 技术栈

- React 19
- TypeScript 5
- Radix Themes
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`。宿主机正式端口由根目录 `docker-compose.yml` 映射为 `10030:80`，源码不硬编码宿主端口。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1030 .
docker run --rm -p 10030:80 sologsb-1030
```

多阶段镜像构建完成后由 nginx 监听容器 `80`，只提供静态前端资源。

## 数据说明

浏览器存储键为 `sologsb-1030-workspace-v1`，主题偏好使用 `sologsb-1030-theme`。当前版本内置 C172 示例检查单及两个历史冻结版本。
